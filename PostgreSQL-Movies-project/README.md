# Database PostgreSQL Programming Project: Movies

## Project Title
Movie Marketplace & Watchlist Database System

## Project Overview
This PostgreSQL database project manages a movie platform where users can buy, rent, order DVDs, create movie lists, view upcoming movies, and browse top-rated movies.

The database supports:
- Digital movie purchases
- Movie rentals
- DVD orders
- User watchlists
- Upcoming movies
- Top-rated movies
- Reviews and ratings
- Payment and order tracking
